# TỔNG KẾT TUẦN 2026-2027

Ứng dụng Android dành cho lớp trưởng nhập vi phạm/khen thưởng theo tuần và gửi dữ liệu về Google Sheet **TỔNG KẾT TUẦN 2026-2027**.

## Đầu ra chính
- `Code.gs`: Google Apps Script backend.
- APK: được GitHub Actions tự động build trong workflow **Build Android APK**.

## Cấu trúc
- `app/`: mã nguồn Android.
- `.github/workflows/android.yml`: workflow build APK.
- `Code.gs`: backend Apps Script.

Google Sheet hiện dùng: `TỔNG KẾT TUẦN 2026-2027`.
